# Project Documentation (`docs/`)

This directory contains technical documentation, academic project reports, architecture diagrams, and algorithm specifications.

## 📚 Documentation Index

1. **System Architecture**: High-level flowcharts, pipeline block diagrams, and data lifecycles.
2. **Algorithm Specifications**:
   - Multi-Camera Trajectory Reconstruction via Shortest Path & Hidden Markov Models (HMM).
   - Multi-frame Plate Voting (Levenshtein distance & Bayesian consensus).
   - Traffic Level of Service (LOS) calculations based on HCM (Highway Capacity Manual) standards.
3. **Database Schemas**: Entity Relationship (ER) diagrams for cameras, detections, trajectories, and traffic metrics.
4. **API Specifications**: OpenAPI / Swagger schema exports and WebSocket protocol specifications.
5. **Project Reports & Presentations**: Final-year thesis chapters, literature reviews, and slide decks.
