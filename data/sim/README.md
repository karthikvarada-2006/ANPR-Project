# Simulation Data Directory (`data/sim/`)

This directory stores files generated by **Module 1 (Simulator)**:
- `city.graphml`: Exported OpenStreetMap drivable road network graph.
- `cameras.csv`: Virtual ANPR camera metadata (ID, coordinates, node, road name).
- `ground_truth_events.csv`: Perfect simulated vehicle passage events.
- `events.csv`: Real-world ANPR camera observations with OCR character noise and missed detections.
- `blacklist.csv`: Monitored/stolen vehicle plates for security alert triggers.
- `anomalies.csv`: Injected anomaly scenarios (e.g., cloned plates detected at far cameras simultaneously).
