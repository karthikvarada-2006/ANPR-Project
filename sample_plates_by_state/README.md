# 🇮🇳 State-wise Vehicle Number Plate Test Images

This folder contains curated vehicle photos organized by Indian state, ready to upload directly into the **Plate Reader** tab.

### Folder Organization
- **`QUICK_SELECTION/`**: Contains the single highest-accuracy vehicle photo for each state with the state name and plate in the filename.
- **`<STATE>_<StateName>/`**: Individual folders for each Indian state containing 1-2 verified test images.
- **`WITH_DATABASE_SIGHTINGS/`**: License plate crops (e.g. `DL8CN63308`, `MH02DN8718`) that match real events recorded in the database and activate the **'🗺️ Reconstruct Trajectory'** button.
